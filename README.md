# Note_Downloads

Note（https://note.com/bluesman1959 ）の記事で配布しているファイルの置き場所です。

## Fender5F1_Champ

記事「自作 5F1 Champ の音を、シミュレーションはどこまで説明できるか ― Claude × LTspice で全段解析と 4 つの改造」の配布ファイルです。

- [ltspice-simulation_20261013.zip](Fender5F1_Champ/ltspice-simulation_20261013.zip?raw=1): Claude Code のスキル `ltspice-simulation`（シミュレーション全体の手順書）一式

使い方は zip の中の「はじめにお読みください.txt」と記事を見てください。

真空管モデル（Koren 氏の `tube1.lib`、中林歩氏のモデル）は含みません。入手先は記事に載せています。

## 05_6V6_compare

記事「Fender 5F1 Champ の 6V6 を 4 本差し替えて実測、LTspice の真空管モデルを AI で合わせ込む ― 3 本は表せて、1 本は表せなかった」の配布ファイルです。

- [6V6_compare_20261031.zip](05_6V6_compare/6V6_compare_20261031.zip?raw=1): 4 本の 6V6 の実測データ、探索の記録、実機モデルの .cir、探索スクリプト、係数なしの `6V6_param.lib` など一式

使い方は zip の中の README.md と記事を見てください。

6V6・12AX7 のモデル（中林歩氏の SPICE 用真空管モデル）と 6V6 の係数は含みません。入手先と用意のしかたは記事の付録に載せています。
